# Pixel Perfect

[PixelPerfect](https://github.com/Haplo064/PixelPerfect) 的台服移植版。在角色身上繪製自訂的範圍指示圖形（例如技能範圍圈、判定線），可依職業與狀態自動顯示。指令 `/pp` 開啟設定視窗。

## 主要功能

- **繪製類型**：圓環、直線、點、虛線圓環、扇形，可調整半徑、分段數、粗細、顏色、偏移與旋轉。
- **顯示條件**：每個圖形可各自設定僅在特定職業、戰鬥中、副本中、拔刀時顯示。
- **編輯器**：視覺化調整圖形大小與位置。
- **匯入／匯出**：可將目前的圖形設定以文字複製到剪貼簿分享，或從剪貼簿匯入他人分享的設定。

## 台服版的修改

- 只做台服相容性修正與介面繁體中文化，功能與上游相同。

## 安裝

`/xlsettings` 開「Dalamud 設定」→「試驗性功能」→「第三方插件倉庫」，加入 `https://raw.githubusercontent.com/ffxiv-tc-port/DalamudPluginsTC/main/repo.json` 並啟用、儲存，再到「插件管理員」（`/xlplugins`）安裝；同一個插件只裝這裡的版本，不要同時裝上游版。
